# Technológiai stack

| Komponens | Technológia | Indoklás |
| --- | --- | --- |
| Backend | Spring Boot 4.0.6 (Java 21) | Elterjedt keretrendszer sok dokumentációval és nagy közösséggel |
| Android | Java + Gradle (KTS) | Java nyelvet ismerve választottam ezt, a Java sokáig elsődleges nyelvként szolgált az Android fejlesztéshez |
| Webadmin | React 19 + TypeScript + Vite | React keretrendszert már használtam, TypeScript pedig nagyon jól működik vele, Vite pedig a gyors teszteléshez szükséges eszköz |
| Adatbázis | PostgreSQL | Komplexebb lekérdezésekhez kiváló, fejlettebb mint egy MySQL, valamint a kapcsolatok végett a lekérdezések gyorsabbak |
| Fejlesztői környezet | Git, GitHub Desktop, IntelliJ IDEA, Webstorm, Postman, Android Studio | Különböző platformokhoz különböző, speciális IDE-ket választottam, Postman és GitHub Desktop pedig az tesztelés és verziókezelés egyszerűsége miatt kell |
